# Mantos App - Tasa de Riego

Aplicación web para registro operativo de mediciones de tasa de riego en procesos de lixiviación minera.

## Contenido principal

- Registro de mediciones de tasa de riego.
- Historial local de registros.
- Exportación de reporte Excel.
- Glosario técnico con modo de prueba.
- Módulo de conducción para documentación operacional.
- Modo claro y modo oscuro.

## Uso local

Abrir `tasa-riego-preview.html` en un navegador.

## Notas

Los archivos APK, ZIP y carpetas de compilación Android se excluyen del repositorio porque son artefactos generados.
